# srp-RAG-mcp-server

## 目录介绍

### dist目录
这里是放置通过tsc编译后的文件，通过node指令来运行js文件。
在package.json里我已经配置好了简便的指令，不需要过多在意。

### docker_project_MCP目录
这个目录下面存放的是我们在docker部署的一些数据，比如配置文件和data目录。这个目录你可以不放在这里，随便找个地方方也行，这个目录主要是用来启动相关的docker服务的。目录的名字你也可以自定义。

### docs目录
这里存放需要进行解析入库的文档。
目前打算作为一个临时存放的目录，在完成文档的解析入库后，文档应该被删除，只保留向量数据库里的数据。

### node_modules
这个不用多说，存放node的包的目录，注意gitignore文件里一定要设置不要上传这个文件目录。

### src目录
这里存放我们的源代码
